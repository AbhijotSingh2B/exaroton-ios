<h2 id="header-authentication">Authentication <a class="permalink" href="#header-authentication" aria-hidden="true">¶</a></h2>
<p>To authenticate your requests, you need a valid API token.
This token can be generated in your <a rel="noopener noreferrer" href="https://exaroton.com/account/" target="_blank">exaroton account settings</a> and needs to be sent in the <code>Authorization</code> HTTP header with every request you make.</p>
<pre><code><span class="hljs-attribute">Authorization</span>: <span class="hljs-string">Bearer {token}</span></code></pre>
<h1 id="header-websocket-api">Websocket API <a class="permalink" href="#header-websocket-api" aria-hidden="true">¶</a></h1>
<p>The websocket API allows a constant connection to our websocket service to receive events in real time without polling
(e.g. trying to get the server status every few seconds).</p>
<p>You can use our <a rel="noopener noreferrer" href="https://www.npmjs.com/package/exaroton" target="_blank">Node.js library</a> as a reference implementation.</p>
<pre><code><span class="hljs-string">https:</span><span class="hljs-comment">//api.exaroton.com/v1/servers/{server}/websocket</span></code></pre>
<h2 id="header-basic-messages">Basic messages <a class="permalink" href="#header-basic-messages" aria-hidden="true">¶</a></h2>
<p>All messages received from or sent to the websocket are JSON strings.
Every JSON object has a <code>type</code> property, and may additionally have a <code>data</code> and a <code>stream</code> property.</p>
<p><strong>ready</strong></p>
<pre><code class="language-json">{"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"ready"</span></span>,"<span class="hljs-attribute">data</span>":<span class="hljs-value"><span class="hljs-string">"6L5WWSK73YnWGHQE"</span></span>}</code></pre>
<p>Sent after opening a websocket connection. <code>data</code> is the ID of the server you connected to.
Before this message is received, no messages should be sent to the websocket.</p>
<p><strong>connected</strong></p>
<pre><code class="language-json">{"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"connected"</span></span>}</code></pre>
<p>Sent when a connection to a running game server is established.</p>
<p><strong>disconnected</strong></p>
<pre><code class="language-json">{"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"disconnected"</span></span>,"<span class="hljs-attribute">data</span>":<span class="hljs-value"><span class="hljs-string">"invalid-status"</span></span>}</code></pre>
<p>Sent when a connection to a game server failed or was lost. <code>data</code> includes the reason for the disconnect.</p>
<p><strong>keep-alive</strong></p>
<pre><code class="language-json">{"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"keep-alive"</span></span>}</code></pre>
<p>Sent when if no other messages were sent for a longer period of time. This message can be ignored.</p>
<h2 id="header-streams">Streams <a class="permalink" href="#header-streams" aria-hidden="true">¶</a></h2>
<p>Messages that include a <code>stream</code> property are a part of a specific data stream. There are 5 different data streams available in our WebSocket API:</p>
<h2 id="header-status">status <a class="permalink" href="#header-status" aria-hidden="true">¶</a></h2>
<p>By default, you are always subscribed to server status changes. The only message type in this stream is <code>status</code></p>

<h2 id="header-console">console <a class="permalink" href="#header-console" aria-hidden="true">¶</a></h2>
<p>The <code>console</code> stream can be used to receive a live feed of the server’s console output.
Note that this is the server’s raw console output, so it might contain both ANSI escape codes and control characters.</p>
<p>You can subscribe to the <code>console</code> stream by sending a <code>start</code> message while the server is running:</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"console"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"start"</span></span>,"<span class="hljs-attribute">data</span>":<span class="hljs-value">{"<span class="hljs-attribute">tail</span>":<span class="hljs-value"><span class="hljs-number">0</span></span>}</span>}</code></pre>
<p>The <code>tail</code> option can be used to receive up to 500 lines from the previous console output.</p>
<p>You can unsubscribe by sending a <code>stop</code> message:</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"console"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"stop"</span></span>}</code></pre>
<p>Additional to receiving console output, this stream can also be used as a faster way of sending commands to the server:</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"console"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"command"</span></span>,"<span class="hljs-attribute">data</span>":<span class="hljs-value"><span class="hljs-string">"say Hello World!"</span></span>}</code></pre>

<p>A <code>started</code> messages is sent when the stream was started successfully.</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"console"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"started"</span></span>}</code></pre>
<p><strong>line</strong></p>
<p>Console <code>line</code> messages include a line of console output.</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"console"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"line"</span></span>,"<span class="hljs-attribute">data</span>":<span class="hljs-value"><span class="hljs-string">"[14:20:56] [Server thread/INFO]: [Server] test"</span></span>}</code></pre>
<h2 id="header-tick">tick <a class="permalink" href="#header-tick" aria-hidden="true">¶</a></h2>
<p>The <code>tick</code> stream provides information about the servers current in-game tick speed.
Note that this stream is only available for Minecraft Java Edition 1.16+.</p>
<p>You can subscribe to the <code>tick</code> stream by sending a <code>start</code> message while the server is online:</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"tick"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"start"</span></span>}</code></pre>

<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"tick"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"stop"</span></span>}</code></pre>
<p><strong>started</strong></p>

<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"console"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"started"</span></span>}</code></pre>

<h2 id="header-management">management <a class="permalink" href="#header-management" aria-hidden="true">¶</a></h2>
<p>The <code>management</code> stream can be used to interact with the server using the <a href="https://minecraft.wiki/w/Minecraft_Server_Management_Protocol">Minecraft server management protocol</a>
introduced in 1.21.9. This protocol allows controlling various server settings without restarting the server and
notifies clients of events happening on the server.
Configuring the management server in the server.properties is not necessary, as this is automatically handled by exaroton.</p>
<p>You can subscribe to the <code>management</code> stream by sending a <code>start</code> message while the server is running:</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"management"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"start"</span></span>}</code></pre>
<p>You can unsubscribe by sending a <code>stop</code> message:</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"management"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"stop"</span></span>}</code></pre>
<p>Management requests can be sent by sending a <code>request</code> message. A request consists of the method you would like to call,
its optional parameters and a unique <code>id</code> to identify the response.</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"management"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"request"</span></span>,"<span class="hljs-attribute">data</span>":<span class="hljs-value">{"<span class="hljs-attribute">id</span>":<span class="hljs-value"><span class="hljs-string">"unique-id"</span></span>,"<span class="hljs-attribute">method</span>":<span class="hljs-value"><span class="hljs-string">"minecraft:server/status"</span></span>, "<span class="hljs-attribute">params</span>":<span class="hljs-value">{}</span>}</span>}</code></pre>
<p><strong>started</strong></p>
<p>A <code>started</code> messages is sent when the stream was started successfully.</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"management"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"started"</span></span>}</code></pre>
<p><strong>response</strong></p>
<p>Responses to <code>request</code> messages have the same id provided by the client and the response data from the server.</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"management"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"response"</span></span>,"<span class="hljs-attribute">data</span>":<span class="hljs-value">{"<span class="hljs-attribute">id</span>":<span class="hljs-value"><span class="hljs-string">"unique-id"</span></span>,"<span class="hljs-attribute">data</span>":<span class="hljs-value">{"<span class="hljs-attribute">started</span>":<span class="hljs-value"><span class="hljs-literal">true</span></span>,"<span class="hljs-attribute">version</span>":<span class="hljs-value">{"<span class="hljs-attribute">name</span>":<span class="hljs-value"><span class="hljs-string">"1.21.9 Release Candidate 1"</span></span>,"<span class="hljs-attribute">protocol</span>":<span class="hljs-value"><span class="hljs-number">1073742097</span></span>}</span>}</span>}</span>}</code></pre>
<p><strong>notification</strong></p>
<p>Notifications are sent by the server when certain events happen. The notification type is included in the <code>name</code> property.</p>
<pre><code class="language-json">{"<span class="hljs-attribute">stream</span>":<span class="hljs-value"><span class="hljs-string">"management"</span></span>,"<span class="hljs-attribute">type</span>":<span class="hljs-value"><span class="hljs-string">"notification"</span></span>,"<span class="hljs-attribute">data</span>":<span class="hljs-value">{"<span class="hljs-attribute">name</span>":<span class="hljs-value"><span class="hljs-string">"minecraft:notification/allowlist/added"</span></span>,"<span class="hljs-attribute">data</span>":<span class="hljs-value">[{"<span class="hljs-attribute">id</span>":<span class="hljs-value"><span class="hljs-string">"22c777bb-e823-4ab8-b17b-acd3eef0b597"</span></span>,"<span class="hljs-attribute">name</span>":<span class="hljs-value"><span class="hljs-string">"exaroton"</span></span>}]</span>}</span>}</code></pre>
